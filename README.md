# VOCALCHAX

VOCALCHAX is an original Windows VST3 vocal transformation project built with JUCE.

This repository contains clean-room code and does not include Dreamtonics Vocoflex code, assets, models, or licensing/activation bypasses.

## Features
- Real-time VST3 vocal processing
- Pitch and formant controls
- Brightness, body, air, aggression, smoothness, dynamics and breath shaping
- Dry/wet and input/output gain
- XY morph pad
- MIDI waypoint recall
- Preset/state serialization
- Optional ONNX Runtime inference hook for consent-based voice models
- Windows GitHub Actions build

## Build
Push to `main` or run the **Build Windows VST3** workflow manually. The VST3 artifact is uploaded by GitHub Actions.
